# GooDraw — Estudo & Desenho sobre Questões

> Desenhe, grife e retenha questões em qualquer página da web. Sincronizado na nuvem com Supabase para PC, Celular e Tablet.

## 🌐 Acesso Online
- **Simulador Interativo & Barra de Desenho**: [https://daniellucas2025.github.io/goodraw/](https://daniellucas2025.github.io/goodraw/)
- **Cloud Dashboard (Caderno de Erros, Prints, Grifos)**: [https://daniellucas2025.github.io/goodraw/dashboard.html](https://daniellucas2025.github.io/goodraw/dashboard.html)
- **Download da Extensão (.zip)**: [goodraw-extension.zip](goodraw-extension.zip)

## 📦 Como Instalar a Extensão no Chrome / Edge
1. Baixe e descompacte o arquivo `goodraw-extension.zip`.
2. Acesse `chrome://extensions` no navegador.
3. Ative o **Modo do desenvolvedor** no canto superior direito.
4. Clique em **Carregar sem compactação** e selecione a pasta extraída.
